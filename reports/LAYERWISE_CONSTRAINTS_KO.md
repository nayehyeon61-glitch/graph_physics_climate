# 층별 물리 제약(stage5a · stage5b · stage5c) 결과 종합

작성 2026-11-03 18:30 KST. 설계: `docs/design/Layerwise_Physical_Constraints_KO.md`. 비교표: `reports/compare_stage5a.md`, `reports/compare_stage5b.md`, `reports/compare_stage5c.md`. 원장: `docs/EXPERIMENT_STAGES_KO.md`.

감자의 제안(「물리제안」)은 PINN식 제약을 세 층에 나눠 넣는 것이었다: (1) guide 층 — 경향을 고정 해석 역학 F(X)와 학습 닫힘 S_θ로 구조화, (2) Dynamics 층 — PDE 잔차 손실, (3) Noise 층 — 허용조건(q ≥ 0, 질량·기둥수분 보존)을 사영과 손실로. 규칙대로 각 층을 별도 stage로 두고 바로 앞 stage와 같은 데이터·step으로 비교했다(결정론: 2019년 90 초기시각, 11변수 WB2 RMSE; 앙상블: 24 h, 45 사례, 8 멤버).

## 2. 읽는 법

1. **제약은 "어느 층에 넣느냐"에 따라 효과가 갈렸다.** 결정론 층(guide·Dynamics)의 제약은 RMSE를 거의 바꾸지 못했고(±1 % 안), 확률 층(Noise)의 제약은 CRPS·산포·보존량을 모두 개선했다. 결정론 예보는 이미 데이터 적합이 강해 물리 제약이 추가 정보를 주지 못하지만, 앙상블 생성은 제약이 없으면 평균 편향과 과소산포가 생기고 보존량을 깨므로 제약이 직접 효과를 낸다.
2. **stage5c의 이득은 평가 시 사영이 아니라 학습 시 제약에서 온다.** 사영 전후 CRPS가 같다. L_mean(앙상블 평균 = 결정론 예보, 비편향 쌍 추정량)이 평균 편향을 줄이고, 사영을 통과한 L_feas가 생성 분포 자체를 허용집합 쪽으로 옮겼다. 평가 시 사영은 위반을 정확히 0으로 만든다(비용 +24 %).
3. **stage5a의 해석항은 "정확한 물리"가 아니라 "보정된 2D 근사"였다.** `resolved_fraction.py`로 측정한 대로 코리올리·기압경도력은 각각 경향 분산의 50–80배로 지균 상쇄되어, 보정계수 없이는 쓸 수 없고 보정계수를 써도 설명분산이 9–29 %다. 닫힘이 나머지를 메우므로 자유 head와 차이가 없어진다. 완전한 3D 원시방정식(stage6 1층 DEC flux 핵, 또는 stage10 fcn21의 기둥 정보)이 있어야 F가 의미 있는 비중을 갖는다.
4. **PDE 잔차 손실은 겨냥한 양(잔차)을 5 % 줄였고 RMSE는 그보다 작게 좋아졌다.** 잔차 자체가 관측에서도 0.361(정규화)이라, 잔차 0은 목표가 아니고 λ를 키우면 관측과 멀어진다. λ = 0.1이 적정 범위로 보인다.

## 3. stage9 통합 구조에 반영할 것

- Noise 층: stage5c 방식(사영 + L_feas + L_mean) **채택**. stage3(또는 stage10a/stage11a 중 더 나은 결정론) 위에서 다시 학습해 절대 CRPS를 확정.
- Dynamics 층: PDE 잔차 손실은 옵션(λ = 0.1) — stage9에서 켠/끈 비교 1회.
- guide 층: 닫힘 구조는 보류; 경향 head 유지. stage8b(ODE drift)와 stage11a(곡률 연산자)의 결과에 따라 guide 입력·출력을 결정.
- 평가: ClimODE 열은 결정론 RMSE만 있다(공유 5변수). ClimODE의 방출 잡음으로 앙상블을 만들어 CRPS를 같은 프로토콜로 재는 것은 후속 작업.
