# stage18 결과: graph tendency core (2026-11-09 20:10 KST)

**결론: 채택(기준 통과, 세 연도 모두 5/5 개선).** stage18은 stage17c(ODE 4×6 h 동적 guide + Lie 수송 drift) 위에 **graph tendency core**를 더한 run입니다. 각 6 h sub-step의 변화를 X_{k+1} = SL_{β⊙V}(X_k) − div_G J_θ + S_θ로 쓰고, V = guide의 흐름(17c flow head)을 X_k에서 다시 계산한 것, β = 변수·층별 수송 비중(V-Net head, (−0.5, 2)로 clamp), J_θ = 면(face) 보존 flux, S_θ = 자유 source입니다. core 항은 PIGT에 토큰 C로도 들어갑니다. guide와 guide 없는 짝은 stage17c 것을 그대로 쓰고(평가의 `no_guide`·`physics_only` 값이 17c와 동일), V-Net만 stage9b 가중치에서 1000 step 미세조정했습니다(파라미터 981,732; 17c 962,542). 부호 규약은 + = 개선입니다.

- **core는 guide를 더 쓰게 만들었습니다.** guide 없는 짝이 같으므로 guide 이득의 증가(24 h +5.63 → +6.47 %)는 전부 core 구조의 효과이고, 예보 오차 개선(+0.9 %)과 거의 같은 크기입니다. P=0 손실이 +115 → +95 %로 준 것은 guide 정보가 P 토큰 한 길이 아니라 core(β 수송 V)로도 들어가 P를 0으로 해도 일부가 남기 때문으로 봅니다(P 교체 손실은 +107 → +96 %로 같은 폭).
- **그러나 물리 항의 비중은 작습니다.** 구조화된 항(β 수송 + 보존 flux)은 sub-step 변화의 13~18 %만 설명하고 나머지는 자유 source S_θ입니다(rms S가 T의 8배). β는 step 250에 0.1 근처로 수렴한 뒤 움직이지 않았고, PIGT는 core 토큰에 어텐션의 1 %만 줍니다 — 모델은 guide 흐름으로 수송하는 것보다 source로 직접 쓰는 쪽을 택합니다. 이것이 stage21a(β 초기값 1 + source 예산 벌점)가 겨누는 지점이고, 비중은 lead가 길수록(0.13 → 0.18) 조금 늘어납니다.
- guide만의 예보(physics_only)는 17c와 같습니다(24 h persistence 대비 +33 %).
