# 물리 가이드 보강 결과: 기존 guide / 보강 guide / guide 없음

기준 run `runs/era5_64x32` (기존 guide) 와 새 run `runs/era5_64x32_physops` (보강 guide). 두 run은 데이터(2016–17 학습, 2018 보정, 2019 테스트), 정규화, V-Net 구성과 학습 step(Stage A 1000 / B 1500, batch 4, cosine LR 1e-3), 평가 초기 시각(90개, stride 16×6 h)이 같고 guide만 다르다. `no_guide`는 guide와 무관하므로 기준 run의 것을 그대로 재사용했다 (두 run의 no_guide 수치가 같은지 아래에서 확인).

보강 내용: (1) 고정 등변 물리 연산자(기울기·발산/회전·스칼라/벡터 이류·코리올리·절대와도 이류/신장·라플라시안)를 guide의 최상위 메시 임베딩에 입력, (2) Stage A에 6 h 경향 예측 head 추가(가중치 1.0). guide 크기(cs 32/cv 8)와 융합 게이트 초기값(0.1)은 그대로다.

## 4. 해석

1. **기여도 문제는 해결되었다.** 학습된 V-Net에서 guide 특징을 0으로 하면 24 h MSE가 +121 % (기존 guide +19 %), 다른 시각 것으로
   바꾸면 +159 % (기존 +8 %) 나빠진다. guide 특징만으로 본 24 h 경향 probe R²는 0.17 → 0.32로 올랐고(고정 연산자만으로 0.28),
   융합 게이트 |β|도 0.10–0.125 → 0.13–0.18로 움직였다. 즉 보강된 guide는 역학 정보를 담고 있고 V-Net은 그것을 핵심 입력으로 쓴다.
2. **그러나 예보 정확도는 개선되지 않았다.** 2018 검증(정규화 MSE, 11채널 평균)은 0.0793 → 0.0787로 소폭 좋아졌지만, 2019 테스트
   RMSE는 변수별로 갈린다. 24 h에서 t2m −2.1 %, 850 hPa 바람 −1 %, t850 −0.3 %로 좋아진 반면 z500 +3.0 %, msl +3.5 %로 나빠졌고,
   72–120 h에서는 t2m을 빼고 거의 모든 변수가 1–3 % 나쁘다. guide 없음과 비교하면 24 h에서는 t850/t2m/바람이 1.5–4 % 좋고
   z500/msl은 같지만, 120 h에서는 모두 1–4 % 나쁘다.
3. **열화가 lead와 함께 커지고 대규모 장(z500, msl)에 집중된다**는 패턴은 rollout 증폭을 가리킨다. V-Net이 P에 강하게 의존하는데
   (셔플 +159 %), 다단계 rollout에서는 P가 모델 자신의 예보 상태로부터 계산되므로 예보 오차가 P를 거쳐 증폭된다. Stage A는 백색
   잡음(σ ≤ 0.5)에 대해서만 강건하게 학습되었고 구조적인 예보 오차는 본 적이 없다. 또 1-ring 연산자는 국소적이어서 6 h 경향의
   국소 성분(온도·하층 바람)은 잘 설명하지만 24 h 이상 z500 변화는 대규모 전파가 지배한다.
4. 단일 seed 결과이며, 1–3 % 차이는 seed 잡음과 겹친다(기존 run에서도 guide vs 없음 차이가 ±1–3 %였다). 다만 P 의존도 변화(+19 % → +121 %)는
   잡음으로 설명되지 않는 크기다.
