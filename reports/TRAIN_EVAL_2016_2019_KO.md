# 본 학습 결과: ERA5 64×32, 2016–2017 학습 → 2019 테스트 (CPU)

실행: `bash scripts/run_pipeline.sh` (2026-11-02, 4 CPU 코어, 총 약 1시간 45분). 원자료: `runs/era5_64x32/eval.json`, 학습 로그 `runs/era5_64x32/log_*.jsonl`, 체크포인트 `runs/era5_64x32/*.pt`.

## 설정

- 데이터: WeatherBench2 ERA5 64×32 (5.625°, 6시간 간격), 예측 간격 24시간
  - 학습 2016–2017 (2918쌍), 검증·Stage C 학습 2018 (1456쌍), 테스트 2019 (초기 시각 90개, 4일 간격, 1~5일 rollout)
- 변수: 스칼라 z500, t850, q700, t2m, msl / 접벡터 (u850,v850), (u500,v500), (u10,v10)
- 그래프: icosahedral 2562 / 642 / 162 노드. 파라미터: guide 27.4만, Lie-guided V-Net 55.5만, guide 없는 V-Net 44.8만, denoiser 11.8만
- 학습: Adam, cosine LR 1e-3, batch 4, Stage A 1000 step / B 1500 step / B(no guide) 1500 step / C 800 step (각 11 / 40 / 22 / 19분)

## 해석

1. **결정론 예측은 학습이 되었다.** 24시간 lead에서 모든 변수의 RMSE가 persistence보다 35–60% 낮고, 5일까지 rollout해도 발산하지 않으며 persistence·기후값보다 낮게 유지된다(z500 5일: 771 vs 1007 vs 1073 m²/s²). 다만 5.6° 격자, 2년 학습, 55만 파라미터 모델이므로 절대 수준은 운용 모델과 비교할 단계가 아니다.
2. **물리 가이드의 기여는 작다.** Lie-guided 모델이 1–3일에서 대부분 변수에서 1–3% 낮은 RMSE를 보이지만, 4일 이후에는 차이가 사라지거나 뒤집힌다(z500 5일: +1.5%). 단일 seed이고, Lie-guided 모델의 파라미터가 24% 더 많으므로(융합층) 설계안 §10의 "동일 용량" 비교가 아니다. 이 결과로는 물리 가이드가 도움이 된다고도, 안 된다고도 말할 수 없다.
3. **Stage C는 아직 trivial 기준선 수준이다.** diffusion 앙상블의 CRPS는 독립 Gaussian 잡음 앙상블과 거의 같고(t2m만 12% 낮음), 두 앙상블 모두 앙상블 평균 RMSE가 결정론 예측보다 높다. 즉 생성기가 조건부 잔차 구조(편향 보정, 공간 상관)를 아직 학습하지 못했고 잡음을 더하는 정도다. 800 step, 1456쌍의 학습량으로는 예상 범위다.
4. 바람 변수의 Lie-guided 이득(u/v 500, 850에서 1–2.5%)이 스칼라보다 일관되는데, 이는 접벡터 표현과 관련이 있을 수 있으나 역시 seed 반복이 필요하다.

## 다음 단계로 의미 있는 실험

- seed 3개 이상, 동일 파라미터 수의 비등변 guide(설계안 §10 2행)와의 비교
- Stage B에 다단계 rollout 손실 추가(2–3 step), 학습 기간 확대(예: 2010–2017)
- Stage C 학습량 확대와 잔차의 공간 상관·spread–skill·rank histogram 평가
- GPU에서 1.5° KAI 격자(`mesh_splits=(5,4,3)` 이상)와 PG-Flow 일 평균 계약으로 이동
