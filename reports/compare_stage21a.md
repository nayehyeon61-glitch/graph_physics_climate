# stage21a 결과: 물리 우선 core (2026-11-13 10:50 KST)

**결론: 물리 목표는 달성, 예보 점수는 약 1 % 손해(RMSE 규칙상 기각, 체인 base는 stage18 그대로).** stage21a는 stage18 설정에서 core의 수송 비중 β를 0이 아니라 1에서 시작하고(`core_beta_init 1`), Stage B 손실에 V-Net source의 제곱 비중 벌점 λ·‖S_θ‖²/‖ΔX‖²(λ 0.1, `--source-penalty 0.1`)을 더한 run입니다(감자 2026-11-09 15:07 KST "1+2로 진행"의 1번). 목적은 경향의 대부분을 V-Net source S가 아니라 물리 항 P(guide 흐름 수송 T + 보존형 간선 flux F + 확산 D)가 맡게 하는 것이었습니다. guide와 guide 없는 짝은 stage18 것을 그대로 썼습니다. 부호 규약은 + = 개선입니다. 설계서의 판정 기준은 물리 항 비중 ≥ 0.5, guide 이득 증가, RMSE ±1 % 안이었습니다.
