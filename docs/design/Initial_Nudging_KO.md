# 초기 증분 nudging (stage14b): "초기 보정을 nudging 구조로 강화"

출처: 감자 2026-11-04 11:56 KST — "초기에 nudging 구조를 통해서 초기 보정도 조금 더 강화하면 어떨까요?" (stage14a 초기 경향 입력 뒤).

## 1. NWP의 nudging과 우리 문제

수치예보의 nudging(뉴턴 완화)은 모델 경향에 완화항 (X_ref − X)/τ 를 더해 모델을 기준장 쪽으로 끌어당기는 자료동화 기법이다. 예보 모델에서 "초기"에 쓸 수 있는 유일한 추가 정보는 과거 관측이므로, 기준장은 과거에서 와야 한다. stage14a는 관측 변화 X_t − X_{t−24h}를 V-Net **입력**으로 주어 모델이 알아서 쓰게 했다. stage14b는 한 걸음 더 나가 **모델 자신의 직전 오차**를 명시적으로 완화항으로 넣는다.

## 2. 설계

1. **사전 예보(pre-forecast)**: 초기시각 t에서 직전 상태 X_{t−24h}로부터 모델이 초기시각을 예보한다: X̂_t⁻ = M(X_{t−24h}) (기울기 없음, 자기 자신은 nudging 없이).
2. **증분(analysis increment)**: e_t = X_t − X̂_t⁻ (Δ-scale 단위). 이것은 "지난 24 h 동안 모델이 예측하지 못한 발달"이다. 학습 초기(모델 ≈ persistence)에는 e_t ≈ 관측 경향이고, 모델이 좋아질수록 흐름 의존 잔차 오차가 된다.
3. **완화항**: 첫 step의 변화량을
   Δ' = Δ_net + α(F, e_t) ⊙ e_t,  α = σ(MLP([F의 불변량, e_t의 불변량])) ∈ (0, 1)
   로 둔다(`gpclimate/nn/nudging.py`, `InitialNudging`). F는 V-Net의 격자 임베딩(head_dec 출력), α는 변수·격자점별 완화계수(Δt/τ에 해당), 초기값 0.12 균일. 즉 모델이 직전에 놓친 발달을 부분적으로 다음 step에 이어 붙인다(Danforth & Kalnay 2008식 경향 보정의 학습형·국소형).
4. **적용 창**: 두 번째 rollout step부터는 새 관측이 없으므로 e = 0 → 항이 사라진다(IAU처럼 한 lead 창). 학습(2-step rollout)과 추론(5-step)이 같은 규칙.
5. **등변성**: α는 게이지 불변량 [s, |v|]로만 계산되고 e_t는 공변이므로 블록은 SO(2) 등변(`tests/test_nudging.py`).
6. **무엇을 비교하나**: stage14b = stage14a(`prev_state=1`) + `nudge=1`. 다른 모든 것(guide.pt·정규화기·Stage B 1500 step·rollout 2 from 500)은 stage14a와 동일, baseline(guide 없음)도 같은 nudging으로 재학습. 비교 기준 **stage14a**(직전 stage) + stage3 + ClimODE.

## 3. 왜 stage14a와 다른 정보인가

stage14a의 입력 X_t − X_{t−24h}로부터 e_t를 얻으려면 모델이 내부에서 자신의 24 h 예보 M(X_{t−24h})를 다시 계산해야 한다 — 같은 네트워크 한 번 더 깊이 쌓는 셈이라 사실상 불가능하다. 사전 예보를 명시적으로 돌려 주면 (i) 모델이 "방금 틀린 방향"을 선형 경로로 바로 쓰고, (ii) 게이트가 변수·지역·상황별로 얼마나 믿을지 배운다. 가설: 24–48 h 중위도·극 격차(`reports/error_diagnostics_era5_64x32_physops_roll.md`)의 일부는 흐름 의존적으로 **지속되는** 초기 발달 오차이고, 직전 lead의 증분이 이를 예측한다.

## 4. 구현 요약

| 항목 | 내용 |

| 설정 | `VNetConfig.nudge`, `nudge_hidden`(32); `--nudge 1` → `config.json["nudge"]` |
| 증분 | `LieGuidedForecaster.increment(state, prev_state, prev_cond, g, prev_prev)`; `Run.increment(model, ds, idx, state_n)`가 X_{t−24h}·그 시각의 조건·(prev_state면) X_{t−48h}를 모아 호출, 분할의 첫 lead 구간은 e = 0 |

## 5. 실행과 판정

체인 `runs/era5_64x32_s14b_nudge/chain_s14b.sh`(stage14a 뒤, 11-05 ≈22:20 KST 예상, ≈3.3 h). **가설이 맞으면** stage14a 대비 24 h z500/t850 중위도·극 RMSE가 추가로 좋아지고(≥2 %), 학습된 α가 변수별로 뚜렷이 달라진다(예: z500·msl > q700). α가 0으로 수렴하면 증분은 정보가 없다는 뜻(기각). 채택 기준은 다른 stage와 같다(11변수 평균 5 lead 중 3개 이상 +, P=0 열화 유지). 후속 후보: 증분을 V-Net 입력 채널로도 제공(stage14c), 6 h 사전 예보(stage14d).

## 6. Evensen (2009) *Data Assimilation: The Ensemble Kalman Filter* 와의 대응 (감자 12:06 KST "nudging technique은 이 책을 참고")

책에는 nudging이라는 이름의 기법은 없다(참고문헌 Stensrud & Bao 한 줄뿐). 대신 nudging이 임의로 정하는 완화계수를 **오차 통계로부터 유도**하는 틀이 있고, stage14b는 그 틀로 다시 쓸 수 있다.

| 책 | stage14b | 비고 |
|---|---|---|
| 분석식 ψᵃ = ψᶠ + K(d − Mψᶠ), 칼만 이득 K = Cᶠ/(Cᶠ + C_εε) (3.1, 4.1.1, 9.2) | 초기시각의 "관측" d = 재분석 X_t 자체(C_εε ≈ 0) → K ≈ 1, 분석 증분 = e_t = X_t − M(X_{t−24h}) | 즉 초기 상태 자체는 고칠 것이 없고, 증분은 **지난 step의 모델오차 q의 추정치**다(식 4.5: ψᵗ_k − ψᶠ_k = G(…) + q_{k−1}) |
| 모델오차는 적색잡음 q_k = ρ q_{k−1} + √(1−ρ²) w_k, ρ = 1 − Δt/τ (식 11.33, 12.1–12.3), corr(q_i, q_j) = ρ^{\|i−j\|} (11.34) | 첫 step에 α ⊙ e_t 를 더한다 = E[q_{k+1} \| q_k] = ρ q_k. **α가 곧 ρ** (시간 비상관 길이 τ = Δt/(1−α)) | 책은 ρ를 지정하고, 우리는 상태 의존적으로 학습한다 |
| 12.1.4 "Updating model noise using measurements": 상태를 q로 증강해 분석 때 각 멤버의 실제 모델오차를 추정하고 다음 예보로 **이월**(Reichle et al. 2002) | 증강 상태의 q 역할 = `carried_nudge()`: step k에 더한 항 α_k ⊙ q_{k−1}을 다음 step의 q로 넘긴다 → rollout에서 α^k e_t 로 기하 감쇠 | 처음 설계(첫 step만, IAU식 창)는 ρ = 0 이월에 해당 → `nudge_carry=0` 옵션으로 남김 |
| ρ는 사전에 정해야 하는 매개변수(12.1.1) | `scripts/model_error_autocorr.py`: 보정 기간에서 e_prev = X_t − M(X_{t−24h}), e_next = X_{t+24h} − M(X_t)의 상관 ρ̂(변수·위도대별), 최적 선형 이월계수 β, 선형 이월이 지우는 다음 step MSE 비율 ρ̂² | ρ̂가 0에 가까우면 가설 자체가 약하다는 뜻이고, 학습된 α의 초기값(`nudge_alpha_init`)과 사후 점검 기준이 된다 |

조정 결과: (1) 이월(carry) 기본 켬 — 학습·검증·평가·rollout 모두 step k의 추가항을 step k+1의 증분으로 사용; (2) α 초기값을 측정된 ρ̂로 둠; (3) 판정에 "학습된 α(채널 평균) vs ρ̂" 비교를 추가. 책이 주는 상한: 선형·전역 계수라면 24 h MSE 감소율 ≈ ρ̂² — 아래 측정값 참조.
